# talk-to-a-folder

A new project created with Intent by Augment.

## Color Scheme

This application uses a purple and yellow color theme for a modern and vibrant user interface.

### Primary Colors (Purple)
- Primary: `#9333ea` (Purple-600)
- Primary Light: `#c084fc` (Purple-300)
- Primary Dark: `#6b21a8` (Purple-800)

### Accent Colors (Yellow)
- Accent: `#facc15` (Yellow-400)
- Accent Light: `#fef08a` (Yellow-200)
- Accent Dark: `#ca8a04` (Yellow-600)

### Usage
The color scheme is defined in `apps/web/src/app/globals.css` using CSS custom properties and can be used throughout the application via:
- CSS variables (e.g., `var(--color-primary)`)
- Tailwind utility classes (e.g., `bg-primary-600`, `text-accent-400`)
